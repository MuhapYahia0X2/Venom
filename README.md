# Blog

## Setup
1. Create a GitHub repo named `USERNAME.github.io`.
2. Replace `USERNAME` and your details in `_config.yml`.
3. Push these files to the `main` branch.
4. Repo Settings → Pages → Deploy from branch → `main` / root.

## Run locally
```
bundle install
bundle exec jekyll serve
```
Open http://localhost:4000

## New post
Add `_posts/YYYY-MM-DD-title.md`.
